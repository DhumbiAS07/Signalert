# 🚦 Signalert

**AI-powered community road sign damage reporting and municipal resolution dashboard.**

Signalert empowers citizens to report damaged, faded, obstructed, or missing road signs in real time while providing municipal authorities with an interactive dashboard to verify, prioritize, and resolve infrastructure issues efficiently.

---

## ✨ Key Features

- **🤖 AI-Powered Damage Analysis:** Automatically analyzes uploaded road sign photos using **Gemini AI** to identify sign types, classify damage severity, and generate structured incident reports.
- **📍 GPS & Interactive Mapping:** Captures precise geolocation data and displays reported incidents on an interactive **Google Maps** interface for both public visibility and municipal dispatch.
- **👥 Dual-Role Dashboards:**
  - **Public Portal:** Allows community members to snap/upload photos, pin locations, and track the resolution status of local reports.
  - **Municipal Dashboard:** Enables city officials to review incoming reports, filter by severity or status, assign maintenance crews, and mark issues as resolved.
- **⚡ Real-Time Sync & Security:** Backed by **Firebase Firestore** with custom security rules (`firestore.rules`) for real-time updates and role-based data protection.
